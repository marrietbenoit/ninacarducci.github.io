
# Nina Carducci — Optimisation SEO et Accessibilité

## Présentation du projet

Ce projet a été réalisé dans le cadre de ma formation Intégrateur Web chez OpenClassrooms.

L'objectif était d'optimiser le site portfolio de Nina Carducci, photographe professionnelle, afin d'améliorer ses performances, son référencement naturel (SEO) et son accessibilité.

Le travail a consisté à analyser le site existant, identifier les problèmes techniques et apporter des corrections tout en conservant son apparence et ses fonctionnalités.

### Objectifs

- Améliorer les performances et les temps de chargement.
- Optimiser les images et les ressources du site.
- Améliorer le référencement naturel (SEO).
- Corriger les problèmes d'accessibilité.
- Conserver un affichage responsive sur mobile et ordinateur.
- Vérifier les améliorations à l'aide d'outils d'audit.

### Site en ligne

https://marrietbenoit.github.io/ninacarducci.github.io/



## Technologies et outils utilisés

### Technologies

- HTML5 : structure et contenu des pages.
- CSS3 : mise en forme et adaptation responsive.
- JavaScript: fonctionnalités interactives du site.
- Bootstrap : mise en page responsive et composants interactifs.

### Outils

- Visual Studio Code: modification du code source.
- Google Lighthouse : audits de performance, d'accessibilité, de bonnes pratiques et de SEO.
- PageSpeed Insights: mesure des performances du site en ligne sur mobile et ordinateur.
- Chrome DevTools : analyse du chargement des ressources, des images et des performances.
- PurgeCSS: suppression des règles CSS inutilisées de Bootstrap.
- Git et GitHub : suivi des modifications et gestion du code source.
- GitHub Pages : hébergement et publication du site.
